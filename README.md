# Product Analysis Case Study

An interactive bilingual portfolio case study by **Mohammadreza Kohansal**, focused on turning ambiguous product signals into testable, measurable decisions.

## What this case study covers

- Engagement diagnosis and metric interpretation
- RFM-based customer segmentation
- Cohort retention analysis
- Prioritization and experiment design
- Interactive, presentation-ready storytelling
